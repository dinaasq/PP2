# Music Player 🎵

## Description

Interactive music player built with Pygame that supports playlist management and keyboard controls.

## Features

* Play, stop, pause music
* Switch between tracks
* Displays current track name
* Progress bar visualization
* Auto-play next track

## Controls

* P → Play
* S → Stop
* SPACE → Pause / Resume
* N → Next track
* B → Previous track
* Q → Quit

## Requirements

* Python 3
* pygame

## How to Run

```bash
python main.py
```

## Folder Structure

* music/ → place your audio files here (.wav, .mp3, .ogg)

## Notes

* Make sure the music folder exists
* Only supported formats: .wav, .mp3, .ogg
* Files must be directly inside the music folder
