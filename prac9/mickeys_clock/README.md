# Mickey's Clock 🕒

## Description

This application displays a digital-style clock using rotating Mickey Mouse hands.

* Right hand → minutes
* Left hand → seconds
* Updates in real-time using system time

## Features

* Real-time clock synchronization
* Smooth hand rotation using pygame.transform.rotate()
* Simple graphical interface

## Controls

* Close window to exit

## Requirements

* Python 3
* pygame

## How to Run

```bash
python main.py
```

## Files

* main.py → main loop
* clock.py → clock logic
* images/mickey_hand.png → clock hand image
