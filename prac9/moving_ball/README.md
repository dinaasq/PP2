# Moving Ball Game 🔴

## Description

Simple interactive game where a red ball moves across the screen using arrow keys.

## Features

* Smooth ball movement
* Boundary checking (ball cannot leave screen)
* Keyboard input handling

## Controls

* Arrow Up → move up
* Arrow Down → move down
* Arrow Left → move left
* Arrow Right → move right

## Requirements

* Python 3
* pygame

## How to Run

```bash
python main.py
```

## Files

* main.py → game loop
* ball.py → ball logic
