# Practice 6: Python File Handling and Built-in Functions

## 📌 Objective

This practice demonstrates working with files, directories, and built-in Python functions such as map, filter, reduce, zip, and enumerate.

## 🗂 File Handling

Implemented:

* File creation and writing (`w`)
* Reading files (`read()`, `readline()`, `readlines()`)
* Appending data (`a`)
* Copying files using `shutil`
* Deleting files safely

---

## 📁 Directory Management

Implemented:

* Creating directories (`os.makedirs`)
* Listing directory contents (`os.listdir`)
* Getting current directory (`os.getcwd`)
* Moving files between directories

---

## ⚙️ Built-in Functions

Used:

* `len()`, `sum()`, `min()`, `max()`, `sorted()`
* `map()`, `filter()`, `reduce()`
* `enumerate()`, `zip()`
* Type conversion functions (`int`, `float`, `str`)
